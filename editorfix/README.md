This patch will modify WorldEditor.exe with a small hook to load SamAlphaFix.dll on editor startup.



Installation instructions:



1. Serious Sam Alpha build
2. In the root of Serious Sam Alpha, run Editors.reg so that editor can run. WorldEditor uses Windows Registry for storing options and key shortcuts, this file will also associate WLD files with Alpha's world editor.
3. Extract the contents of this folder into Bin and launch PatchWorldEditor.exe (already compiled version can be found in Releases tab)
4. If everything is OK, run WorldEditor.exe and enjoy making levels/researching :)
